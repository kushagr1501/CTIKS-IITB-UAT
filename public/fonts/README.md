# Website fonts

Self-hosted WOFF2 versions of Red Rose, Montserrat, Inter, Laila, and Cormorant. The existing asset record
lists the official Google Fonts CSS API and 19 October 2026 as its source/date. This documentation pass did
not repeat that download. Latin and Latin Extended subsets are included, plus Devanagari for Laila. The
original SIL Open Font Licenses are included in licenses/.

Font families and weights match src/app/globals.css. Browsers load only the subsets and weights used on the
current page; no Google request is required.
