Research cards display stored titles, images, descriptions, and related professors.

## Connections and gotchas

The route reads database areas and visible people. Matching names uses the first visible person found; do not
change duplicate-name behavior during a visual cleanup.

These notes describe code responsibility. Ask your mentor for the human reviewer assigned to this area; the
repository does not name one.
