# Programme presentation

Academic programme pages currently use checked-in content, not an administrator editing table.

Tool terms: [glossary](../../../docs/GLOSSARY.md).

## Open these first

| Path in this folder                | Role                                                      |
| ---------------------------------- | --------------------------------------------------------- |
| `content.ts`                       | Programme and doctoral content.                           |
| `msc-content.ts`                   | Separate mathematics/astronomy and yoga/wellness content. |
| `components/MscDisciplinePage.tsx` | Shared MSc detail presentation.                           |
| `components/ProgrammeAction.tsx`   | Programme action button presentation.                     |

## Connections and gotchas

Do not imply an admissions link or coming-soon item is an active application system. Confirm academic facts
with the content owner before publishing changes.

These notes describe code responsibility. Ask your mentor for the human reviewer assigned to this area; the
repository does not name one.
